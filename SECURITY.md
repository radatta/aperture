# Security

Aperture is a personal project with one maintainer.

## Reporting

Report a vulnerability privately: this repository's **Security** tab → **Report a vulnerability** (GitHub private vulnerability reporting). Issues are off and outside pull requests are closed, so please don't post details anywhere public.

## Scope

In scope: the code in this repository and the stacks deployed from it.

Out of scope: third-party services the app uses, social engineering, and denial of service or other volumetric testing.

## What to expect

Best effort: a reply when the maintainer can, with no response-time promise. There is no bounty.
