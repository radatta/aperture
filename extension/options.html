Aperture LeetCode

On a LeetCode problem, Start opens a sitting in Aperture and this extension sends what LeetCode itself sends — your code as you type, every Run and Submit with its result, your notes, LeetCode's timer and its replay — using the device token below. Your LeetCode credentials are never sent.

Scheme + host. Sittings go to <origin>/api/lcSittingStart and lcSittingEvents. Saving asks for permission to reach this origin.

Sent as Bearer <token> in the Aperture auth header.

Debug mode

Records what you click on LeetCode, the dialogs it opens and its timer's state — never your code or tokens. Reload the LeetCode tab after turning it on.

Selectors

Where LeetCode's reset, its confirm and its timer controls are, as JSON over the built-in defaults (keys: editorReset, resetConfirm, dialog, timerOpen, timerStart, timerReset, timerResetConfirm, lang, run, submit), each a CSS selector; null turns a step off. Empty means the defaults.
