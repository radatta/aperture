## areas/ — per-domain design docs

- **[areas/tasks/due-dates.md](areas/tasks/due-dates.md)** — **task due dates + times**: a `dueDay` (when it's due, distinct from `taskPlans.day`) plus an optional `dueTime`, free metadata outside the estimate lock; flat display for untimed deadlines, a gold→red urgency colour for timed ones. Decision log + build record.
- **[areas/tasks/bulk-add.md](areas/tasks/bulk-add.md)** — **bulk add tasks**: paste many lines → many backlog tasks with a strict inline `~estimate #category due:date[@HH:MM] notes:"…"` grammar — **read the "Operator reference" section before generating a bulk paste**. The same one-line grammar is optional in capture's Task mode, with tappable token suggestions. Decision log + build record.
- **[areas/tasks/task-editor.md](areas/tasks/task-editor.md)** — the **task detail-and-edit modal**: tap a title and the whole task opens in one surface (hosted by the page, so Save keeps it open even when the row moves); the card slims to lifecycle. Decision log + build record. **Series rename-sync is deferred** (a linked calendar event is renamed).
- **[areas/tasks/split.md](areas/tasks/split.md)** — **split + editable estimates**: the working estimate is editable mid-task (calibration still measures the lock frozen at start); a split never cancels — this part finishes or keeps going, the rest becomes a linked task (`splitFromId`), and split families are excluded from calibration until they're scored as one (piece 3). Decision log + build record.
- **[areas/tasks/lenses.md](areas/tasks/lenses.md)** — **task lenses**: `/tasks` as Today · Week · Backlog · Done over one list, plus Home "+ Add", capture "→ today", and the night "Still open — when?" step. Place table + decision log (`useAddToDay` is the single plan-write path).
- **[areas/tasks/notes.md](areas/tasks/notes.md)** — **task notes**: a free-form `notes` field (light markdown, 5,000-char cap) rendered in the task editor, searched on `/tasks` ("in notes" hint), marked on the row with no snippet, settable from bulk add and MCP. Markdown subset, link allowlist, why the renderer is hand-rolled.
- **[areas/tasks/attachments.md](areas/tasks/attachments.md)** — **task attachments**: the first feature that stores **bytes** — DynamoDB metadata plus a _precious_ S3 Files bucket with **presigned-URL** transport. Decision log + build record.
- **[areas/home/right-now.md](areas/home/right-now.md)** — the **daytime home**: a "Right now" card (the Big 3 from today's plan, the in-progress task as a hero with a calm count-up) over a capped "Coming up" deadline radar. Decision log + build record.
- **[areas/home/rolls.md](areas/home/rolls.md)** — **Rolls**: deadline-free ongoing efforts with a **forgiving momentum "contact sheet"** (fills, never resets); a rep is a done task tagged with the roll, never a counter. Decision log + build record.
- **[areas/recruiting/index.md](areas/recruiting/index.md)** — the **LeetCode attempt-capture** module (`/recruiting`): the passive browser extension (Safari daily via a free-signed Xcode build, Firefox AMO-signed), the device-token ingest path versus the JWT read path, and the identity seam (**`DEVICE_USER_ID` must equal your Cognito `sub`**). Operator checklist + what each test surface proves. Read before touching the extension or the ingest endpoint.
- **[areas/recruiting/story-bank.md](areas/recruiting/story-bank.md)** — the **Behavioral Story Bank**: a `stories` entity + tab at `/recruiting/stories` for competency-tagged STAR stories. Design record + build record.
- **[areas/calendar/index.md](areas/calendar/index.md)** — **Google Calendar integration** (multi-account): a morning "day shape" (longest free stretch + fragment count) and real events from tasks, **auto-synced for timed tasks** (create/move/rename/remove, with a visible failure + retry), and **two-way** for those events: a drag, resize or rename in Google comes back onto the task on app open (pull-based, marked "updated from Google"). The as-built design record — the gated `GoogleGateway`, token scheme, callback/CDK gotchas, delete-on-cancel, auto-sync, two-way sync.
- **[areas/calendar/research.md](areas/calendar/research.md)** — **the pre-build research** behind the calendar work: the finding that moved the intervention to estimate time, the four-piece vision (two shipped, two are PR-D), the statistical trap, and the "don't build" list. Reconciled against index.md.
- **[areas/finances/index.md](areas/finances/index.md)** — **Finances** (`/finances`): the three-bucket budget (Parents pay · Budget · I pay, plus Not spending for money out that isn't spending; the All tab adds search and a "Sort into" brush) over Bank of America via **Plaid Trial** — marked billing periods, refund links, rules, the sync Lambda and its **sync-status contract** (one home), the gated Plaid seam + stub hooks, Plaid facts relied on, operator checklist + first-sync sign check. Read before touching the sync or the Plaid gateway.
- **[areas/mcp/index.md](areas/mcp/index.md)** — the **MCP server** (`/mcp`): one endpoint for **Claude Code** (static agent token) and **claude.ai** (Cognito OAuth façade) to read+write Aperture. Design record — the credential-not-method auth fork, the ~25-tool surface (finances read-only), the hand-rolled protocol, the façade decisions (D13/D14), and **voice** — the Claude-app voice capture surface that rides the claude.ai connector, and what it asks of every new feature. Read before touching the MCP surface or generating tool calls.
- **areas/calibration/** — (planned) per-course & intent-vs-actual calibration, exam-prep spacing, this-week's-dues. Design doc lands with that work.
