- **[recruiting/](recruiting/index.md)** — the recruiting hub's docs.
  - **[recruiting/index.md](recruiting/index.md)** — the **LeetCode attempt-capture** module (`/recruiting`): the passive Firefox extension that mirrors LeetCode's own submit/check calls, why metadata comes from the server-rendered DOM rather than GraphQL, the device-token ingest path (scoped to the one write method) versus the JWT read path, and **the identity seam between them — `DEVICE_USER_ID` must equal your Cognito `sub` or capture silently writes rows the page will never show**. - **[COI-SANDBOX.md](COI-SANDBOX.md)** — the **runtime playbook** for running Claude Code on this repo inside an Incus container (day + night profiles). Opens with **Start here — the four things you ever do**: launch Claude, debug at the VM layer, debug inside the container, shut down — each with the exact commands and which of the three layers (Mac / Lima VM / container) to run them at. Then the Lima→Incus stack, one-time setup, the four config files, how to *end* a session (**exiting `coi shell` is what exports** — `coi shutdown` only deletes, and forces a resume that **forks** the session into a new picker entry; reattach with `coi attach` instead — verified 2026-09-07), the **port convention** (5173+ you, 6173+ container), **how to triage a frozen container from the audit log** (read `~/.coi/audit/<name>.jsonl` directly — `coi audit` has a read-path defect), **GitHub access inside the container** (no SSH agent → stale `origin/*` refs are the real hazard; read-only PAT setup, re-done after a VM rebuild, and why write access can't be safely scoped with a single identity), and a one-line index of every known failure signature.
- **[COI-INCIDENTS.md](COI-INCIDENTS.md)** — post-mortems for the sandbox failures that cost hours, kept out of the playbook so it stays short. `SIGABRT (134)` from pids-cgroup exhaustion; a 13-hour unattended run killed by `'Clamshell Sleep'` (and why `caffeinate` doesn't prevent it); the mount change that restarts the whole VM; the shared-`node_modules` hazard; the `limactl edit` typo that rebuilt the VM and deleted two Claude Code sessions (and why `~/.coi/` was never on the Mac), including the full zero-to-working VM bootstrap; the false-positive threat pause and the `coi audit` read-path defect; and the three container **kills** from `python3 -c` matching a hardcoded reverse-shell pattern gated only on the command containing a `:`. Includes the full log map, the ruled-out hypotheses, and the broken commands not to repeat.
