## areas/ — per-domain design docs

- **[areas/tasks/due-dates.md](areas/tasks/due-dates.md)** — **task due dates + times**: a `dueDay` (when it's due, distinct from `taskPlans.day`) plus an optional `dueTime`, free metadata outside the estimate lock; flat display for untimed deadlines, a gold→red urgency colour for timed ones. Decision log + build record.
- **[areas/tasks/bulk-add.md](areas/tasks/bulk-add.md)** — **bulk add tasks**: paste many lines → many backlog tasks with a strict inline `~estimate #category due:date[@HH:MM] notes:"…"` grammar — **read the "Operator reference" section before generating a bulk paste**. The same one-line grammar is optional in capture's Task mode, with tappable token suggestions. Decision log + build record.
- **[areas/tasks/quick-add.md](areas/tasks/quick-add.md)** — **quick add**: capture's Task mode (and the Raycast hotkey) parse a natural line (`aperture, fix x due fri 30m`) with **Claude Haiku**, server-side — Enter saves (Auto), ✨/⌘Enter previews first (Review), `|` keeps the strict grammar, a failed parse saves raw and says so. The first built model call: the gated `AnthropicGateway`, the SSM key + operator step, decision log.
- **[areas/tasks/task-editor.md](areas/tasks/task-editor.md)** — the **task detail-and-edit modal**: tap a title and the whole task opens in one surface (hosted by the page, so Save keeps it open even when the row moves); the card slims to lifecycle; a tap-only **category suggestion** chip (pure-TS naive Bayes over your own tasks, confident-only). Decision log + build record. **Series rename-sync is deferred** (a linked calendar event is renamed).
- **[areas/tasks/split.md](areas/tasks/split.md)** — **split + editable estimates**: the working estimate is editable mid-task (calibration still measures the lock frozen at start); a split never cancels — this part finishes or keeps going, the rest becomes another part. Revised 2026-10-08: a split always yields parent + parts, and `splitFromId` and the family exclusion are retired ([parts.md](areas/tasks/parts.md)). Decision log + build record.
- **[areas/tasks/parts.md](areas/tasks/parts.md)** — **parent + parts**: the deliverable (parent: deadline, done when every part is dealt with — a hard block otherwise) vs the work (parts: planned, worked and measured on their own), one level; parenthood derived from `parentId`; the parent's lock freezes when its first part starts and its actual is Σ parts; a parent's one calendar event is its due marker (15 min, free, graphite; two chokepoints) and its parts' blocks are named after it (v2a, 2026-10-13); a part's own time is when its block ends; nesting in Week/Backlog; Break down… / Add parts…; a timed task's day is its time (v2b, 2026-10-30).
- **[areas/tasks/lenses.md](areas/tasks/lenses.md)** — **task lenses**: `/tasks` as Today · Week · Backlog · Done over one list, plus Home "+ Add", capture "→ today", and the night "Still open — when?" step. Place table + decision log (`useAddToDay` is the single plan-write path; a timed task is on Today by its time, never planned — D13).
- **[areas/tasks/notes.md](areas/tasks/notes.md)** — **task notes**: a free-form `notes` field (light markdown, 5,000-char cap) rendered in the task editor, searched on `/tasks` ("in notes" hint), marked on the row with no snippet, settable from bulk add and MCP. Markdown subset, link allowlist, why the renderer is hand-rolled.
- **[areas/tasks/areas.md](areas/tasks/areas.md)** — **life areas**: every category belongs to School · Aperture · Recruiting · Personal (none = Personal), set once in Settings or MCP; the Backlog is the life backlog with Aperture folded behind an "Aperture · N" chip, Home's "+ Add" counts the rest, Week and Today never filter. Model, surfaces, decisions; the courseId won't-do lives here.
- **[areas/tasks/places.md](areas/tasks/places.md)** — **places (errand lists)**: `@slug` puts a task on a store's list (never a calibration point), a Places lens with one-tap check-off, and `GET /api/places/<slug>/tasks` for an iPhone Shortcuts **Arrive** automation behind a hashed, user-rotated place token. PR 1 of reminders; decision log, threat model, cost bound, the Shortcut recipe.
- **[areas/tasks/recurring.md](areas/tasks/recurring.md)** — **recurring cadences**: a series says when each occurrence is _due_ (`dueOffsetDays`: planned on its day, due N days later, untimed) and when it _ends_ (`until`; the row reads "ended …" until stopped); course = category; the respawn fix (identity by `seriesDay`, never a plan row); MCP `list_series` / `create_series` / `stop_series`; `deleteSeries` for the dev check. Decision log D1–D7 + the respawn record.
- **[areas/tasks/reminders.md](areas/tasks/reminders.md)** — **reminders (Web Push)**: timed deadlines ping at their minute, day-only and planned tasks at 09:00, each toggleable, via a once-a-minute push-dispatch Lambda sending declarative Web Push to the installed PWA; hand-rolled VAPID + RFC 8291, fail-closed dedup + a hidden 50/day guard, visible health and Send test in Settings › Notifications, a GCal popup on timed events. PR 2 of reminders.
- **[areas/tasks/reflection.md](areas/tasks/reflection.md)** — **task reflection**: one optional look back on a finished task (1,000-char cap), written on the Done form with the actual, edited under Notes in the task modal, shown under the delta in the night review, carried by `complete_task` / `update_task` / `get_calibration`. - **[areas/tasks/attachments.md](areas/tasks/attachments.md)** — **task attachments**: the first feature that stores **bytes** — DynamoDB metadata plus a _precious_ S3 Files bucket with **presigned-URL** transport. Decision log + build record; §9 is the operator runbook for sweeping orphaned bytes.
